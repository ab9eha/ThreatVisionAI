# ThreatVision AI 🛡️

## AI-Powered Network Threat Detection Dashboard

ThreatVision AI is an educational cybersecurity project that demonstrates how machine learning can be used to classify potentially suspicious network activity.

The project combines Python, machine learning, data analysis, and an interactive Streamlit dashboard.

## Features

- CSV network-log upload
- Machine-learning-based threat classification
- Normal vs. attack prediction
- Security alerts
- Threat statistics
- Interactive threat visualization
- Reproducible model-training script
